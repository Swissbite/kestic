# Anforderungen

**Prio** (bestätigt 2026-11-15): MVP | P2 (Phase 2) | Luxus | P3 (zuletzt). Anforderungen mit zwei Prioritäten sind in getrennte IDs aufgeteilt. Die FRs sind nach Bereich gruppiert (Ziele, Backups, Ausführung, Restore, Sicherheit, Betrieb) (Q9); die IDs bleiben unverändert und stabil.

Akzeptanzkriterien je Anforderung stehen in den Meilensteinen ([backlog.md](backlog.md), [milestones/](milestones/)); jedes AC nennt die referenzierten FR/NFR-IDs in Klammern.

Vorher Host und Zeit des letzten Snapshots anzeigen; jünger als 7 Tage und von anderem Host → Warnung «Übernehmen heisst: Der andere Rechner soll dieses Backup nicht mehr ausführen» (zwei Rechner auf einer Reihe: ausser Scope, E13).
