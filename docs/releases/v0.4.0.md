Kestic 0.4.0 brings your data back. The new **Restore** tab lists every backup with its snapshots, newest first. Open a snapshot and browse it folder by folder, search all snapshots of a backup for a file name, or compare two snapshots to see which files are new, changed, or removed. **Restore Files…** in the tray opens the same tab.

Mark the files and folders you want and restore them. By default they go into a new folder, so nothing you have is touched. Restoring to the original location, or into a folder that already has files in it, needs a preview first: it lists every file that would be new, overwritten, not overwritten, or unchanged. Existing files are never overwritten unless you choose to, and Kestic asks again before it overwrites anything. At the original location, a home folder saved under another user name maps to yours.

Snapshots that Kestic did not make, for example with plain restic, show up as unassigned, and those of backups it no longer knows as orphaned. You can browse and restore them too; Kestic only reads them.
